# BRIDFORE – Bright Dream Forest v2

> 사람과 배움, 진로와 미래를 연결합니다.

## 프로젝트 개요

BRIDFORE 교육전문 브랜드 홈페이지입니다.  
기존 소개형 홈페이지에서 **사업·소식·자료·언론 콘텐츠가 지속 축적되는 운영형 교육 브랜드 홈페이지**로 확장되었습니다.

---

## 완성된 기능

### 메인 홈페이지 (index.html)
- ✅ **상단 메뉴** – BRIDFORE 소개 / 사업·프로그램 / 소식 / 자료·콘텐츠 / 언론·활동 / 문의
- ✅ **히어로 섹션** – 타이틀 + 교육 문의/강의 요청 버튼 + 기관 협업/상담 신청 퀵메뉴
- ✅ **BRIDFORE 소개** – 브랜드 스토리 + 핵심 가치 4종
- ✅ **BRIDFORE가 하는 일** – 4가지 서비스 카드 (각각 프로그램 페이지 연결)
- ✅ **함께하는 대상** – 청년/중장년/시니어/기관 카드
- ✅ **교육 운영 원칙** – "이렇게 다릅니다" 신뢰 섹션
- ✅ **사업·프로그램** – 카테고리 탭 필터 + 카드 목록 + 상세 모달
- ✅ **소식** – 카테고리 탭 + 리스트 형 + 더보기 + 상세 모달
- ✅ **자료·콘텐츠** – 분류 탭 + 카드 목록 + 파일 다운로드 링크
- ✅ **언론·활동** – 출처/활동주체 표시 + 원문 링크 + 더보기
- ✅ **문의 폼** – 유효성 검사 + API 저장 + 완료 메시지
- ✅ **푸터** – © 2026 BRIDFORE, 법적 링크, 관리자 버튼

### 관리자 대시보드 (로그인 후 진입)
- ✅ **대시보드** – 통계 카드 + 유형/상태 차트 + 최근 문의 목록
- ✅ **문의 관리** – 검색·필터·정렬·상태변경·삭제·CSV 다운로드
- ✅ **사업·프로그램 관리** – 등록/수정/삭제
- ✅ **소식 관리** – 등록/수정/삭제
- ✅ **자료·콘텐츠 관리** – 등록/수정/삭제
- ✅ **언론·활동 관리** – 등록/수정/삭제
- ✅ **통계** – 연령대/유형/월별/상태 차트 4종

## 파일 구조

```
index.html          ← 메인 원페이지 (전체 섹션 통합)
privacy.html        ← 개인정보처리방침
terms.html          ← 이용약관
css/style.css       ← 전체 스타일
js/main.js          ← 전체 기능 (공개 + 관리자)
images/
  logo.png          ← 실제 로고 (교체 필요)
  logo-fallback.svg ← fallback SVG 로고
```
